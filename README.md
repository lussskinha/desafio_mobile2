## Sobre o Projeto
Este projeto é uma aplicação Flutter capaz de realizar **CRUD completo** de Clientes e Produtos, integrada a um backend para armazenamento e gerenciamento de dados.

### Entidades:
- **Clientes**: id, nome, sobrenome, email, idade, foto
- **Produtos**: id, nome, descrição, preço, data_atualizado

---

## Funcionalidades
- Listar, adicionar, editar e remover clientes
- Listar, adicionar, editar e remover produtos
- Validação de campos nos formulários
- Navegação entre telas fluida
- Interface agradável e responsiva
